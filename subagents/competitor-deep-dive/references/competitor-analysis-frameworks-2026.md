# Competitor Analysis Frameworks 2026 — When to Use What

> Reference completa 7 framework consolidati per competitor analysis B2B 2026, con when-to-use per ruolo, esempi reali, fonti citate. Output di Fase A research RQ1.

## I 7 framework consolidati

### 1. SWOT Analysis

**Cosa fa**: Strengths/Weaknesses/Opportunities/Threats per competitor + per cliente. Cross-overlay surface gap strategici.

**Pro**:
- Familiar a tutti i ruoli
- Veloce (1h per competitor)
- Cross-functional (sales, marketing, product condividono linguaggio)

**Contro**:
- Spesso superficiale ("we're better, faster, cheaper")
- Bias confermativo se non grounded in evidence

**When to use**:
- **Founder / CEO**: snapshot rapido pre-investor meeting
- **Sales**: deal-level battlecard
- **Tutti**: punto di partenza prima di framework deeper

**Esempio applicato**:
- Make S: visual UI strong, free tier aggressivo
- Make W: pricing scale enterprise costoso, mobile gap
- Make O: AI-assisted workflow segment emerging
- Make T: n8n self-host pressure, enterprise lock-in concorrenza

**Fonte**: [B2B International — Competitive Landscape Analysis with Porter's Five Forces (2024)](https://www.b2binternational.com/2024/04/04/competitive-landscape-analysis-porters-five-forces/) — *"SWOT works on two levels: you apply it to each competitor to understand their position, and you apply it to your own business in the context of what you have learned"*.

### 2. Porter's Five Forces

**Cosa fa**: Analisi macro industry-level. 5 forze: Rivalry intensity, Supplier power, Buyer power, Threat of substitutes, Threat of new entrants.

**Pro**:
- Macro view (oltre direct competitor)
- Identifica strutturale vs tactical
- Utile per market entry / pivot

**Contro**:
- Slow (richiede industry research)
- Meno actionable a livello tactical
- Non considera customer JTBD

**When to use**:
- **Founder / CEO**: market entry decision, fundraising deck
- **Analyst / Consultant**: due diligence M&A
- **NON usare**: per battlecard sales (over-engineered)

**Esempio applicato (workflow automation industry 2026)**:
- Rivalry: HIGH (Make, Zapier, n8n, Workato + Pipedream + Tray)
- Supplier power: LOW (cloud infra commodified)
- Buyer power: MED-HIGH (procurement scrutiny enterprise)
- Substitutes: HIGH (custom code, AI agents emergenti)
- New entrants: HIGH (low barrier, API + UI = MVP)

**Fonte**: [Slashexperts 2026](https://slashexperts.com/post/building-your-first-b2b-competitive-analysis-step-by-step-framework-with-templates/) — *"Porter's Five Forces analyzes the structural competitive dynamics of an entire industry"*.

---

### 3. Jobs-To-Be-Done (JTBD)

**Cosa fa**: Sposta focus da feature a customer outcome. "Quale 'job' i customer hire il prodotto per fare?"

**Pro**:
- Customer-centric (no feature parity trap)
- Identifica blue ocean ("nessuno fa il job X")
- Cross-segment (B2B + B2C applicabile)

**Contro**:
- Richiede customer research (interview, review mining)
- Difficile per company senza customer base ampia

**When to use**:
- **PM**: roadmap prioritization, feature gap
- **Marketing**: messaging customer-centric
- **Mature programs**: dopo aver SWOT + Feature Matrix

**Esempio applicato**:
- Make: "Build automation 10x faster than manual"
- Zapier: "Connect tools without engineering ticket"
- n8n: "Self-host workflow per data sensitivity"

**Fonte**: [AriseGTM — Jobs-To-Be-Done](https://arisegtm.com/blog/jobs-to-be-done-jtbd) + [Slashexperts 2026](https://slashexperts.com/post/building-your-first-b2b-competitive-analysis-step-by-step-framework-with-templates/) — *"JTBD analysis compares competitors not by features but by the customer outcomes each product enables"*.

---

### 4. Strategy Canvas (Blue Ocean)

**Cosa fa**: Visual one-pager con 8-12 fattori (eg. ease of use, integrations, pricing, support, AI assistance, customisation) scorati 0-10 per competitor + cliente. Plotta value curve.

**Pro**:
- Visual immediate (board-ready)
- Identifica convergence (tutti uguali = blue ocean opportunity)
- Decision-driving (Eliminate / Reduce / Raise / Create framework)

**Contro**:
- Richiede 8-12 fattori giusti (factor selection key)
- Subjective scoring rischia bias

**When to use**:
- **Marketing Manager**: repositioning, messaging differentiation
- **Founder**: strategic bet identification, fundraising deck (board)
- **Workshop**: cross-functional alignment

**Esempio applicato (workflow automation 2026)**:

Fattori scorati 0-10 per Make / n8n / Zapier / Cliente:

| Fattore | Make | n8n | Zapier | Cliente |
|---------|------|-----|--------|---------|
| Ease of use | 9 | 6 | 9 | 7 |
| Integrations breadth | 9 | 7 | 10 | 5 |
| Self-host option | 0 | 10 | 0 | 0 |
| AI-assisted building | 4 | 3 | 5 | 0 |
| Pricing transparency | 8 | 9 | 7 | 8 |
| Time to value | 8 | 5 | 9 | 6 |
| Enterprise security SOC2 | 9 | 8 | 9 | 6 |
| Free tier generosity | 8 | 9 | 5 | 4 |

→ Cliente value curve underperform su Integrations + AI + Time-to-value vs all 3 competitor → strategic bet identificato.

**Fonte**: [Incremys 2026 — Blue Ocean Strategy in B2B](https://www.incremys.com/en/resources/blog/blue-ocean-strategy) — *"strategy canvas...you list 8 to 12 factors such as support, integrations, customisation, time-to-value, security, reporting, expertise, price, and content, then score your offer and alternatives"*.

### 5. Positioning Map 2x2

**Cosa fa**: 2 assi (es. Price vs Feature breadth, Self-host vs Cloud, Casual vs Formal ToV) — competitor plotted come dot, cliente in evidence.

**Pro**:
- Super-visual quick-glance (slide-ready)
- Identifica empty quadrants (potenziale opportunità)

**Contro**:
- Solo 2 dimensioni (semplificazione)
- Asses scelti possono essere arbitrari

**When to use**:
- **Marketing**: visual battlecard per slide deck
- **Sales**: ice-breaker call con prospect
- **Pre-meeting prep**: 5 min snapshot

**Esempio**:
- Asse X: Pricing entry ($0 free → $50+ paid)
- Asse Y: Tech sophistication (No-code → Low-code → Code)
- Make (low price, low-code mid)
- Zapier (low price, no-code low)
- n8n (free OSS, low-code mid)
- Cliente (mid price, low-code mid) → quadrant occupato, differenziarsi su Y vs X

### 6. Competitive Profile Matrix (CPM)

**Cosa fa**: Critical Success Factor (CSF) weighted scoring per competitor. Per esempio CSF = [Brand recognition (0.2), Product quality (0.3), Customer service (0.15), Pricing (0.1), Tech innovation (0.25)]. Score 1-4 per competitor su ogni CSF. Calcola weighted total.

**Pro**:
- Quantitativo (number-driven)
- Aggregable a dashboard
- Comparable cross-time (track shift)

**Contro**:
- CSF selection key (subjective)
- Score 1-4 troppo coarse per nuance

**When to use**:
- **Analyst / Consultant**: client deliverable structured
- **Sales**: leaderboard battlecard
- **Quarterly review**: track shift over time

**Esempio**:

| CSF | Weight | Make | n8n | Zapier |
|-----|--------|------|-----|--------|
| Brand recognition | 0.2 | 3 | 2 | 4 |
| Product quality | 0.3 | 4 | 4 | 3 |
| Customer service | 0.15 | 3 | 3 | 4 |
| Pricing | 0.1 | 3 | 4 | 2 |
| Tech innovation | 0.25 | 4 | 4 | 3 |
| **Weighted total** | 1.00 | **3.45** | **3.35** | **3.25** |

### 7. Feature Matrix

**Cosa fa**: Checkbox feature × competitor. Quale ha cosa.

**Pro**:
- Tactical sales battlecard immediato
- Easy update (add row = add feature)
- Universal comprensione

**Contro**:
- Feature parity trap ("loro hanno X, dobbiamo avere X")
- No customer outcome visibility
- Bias granulare (ogni feature pesa uguale)

**When to use**:
- **Sales**: deal-level objection handling
- **PM**: technical gap snapshot
- **NON usare**: come unico framework — sempre paired con SWOT o JTBD

**Esempio**:

| Feature | Make | n8n | Zapier | Cliente |
|---------|------|-----|--------|---------|
| Visual builder | ✓ | ✓ | ✓ | ✓ |
| Self-host | ✗ | ✓ | ✗ | ✗ |
| AI auto-suggest | partial | ✗ | partial | ✗ |
| Mobile app | ✗ | ✗ | ✓ | ✗ |
| SOC2 Type II | ✓ | ✓ | ✓ | ✗ |
| Free tier | 1k ops | unlimited (self) | 100 ops | ✗ |
| Custom code blocks | ✓ | ✓ | partial | ✗ |

## When to use what — Matrix per ruolo

| Ruolo | Primario | Secondario | Skip |
|-------|----------|-----------|------|
| Founder / CEO | SWOT + Porter 5F + Strategy Canvas | JTBD | Feature Matrix da solo |
| Marketing Manager | Strategy Canvas + Positioning Map + ToV diff | SWOT | Porter 5F (over-engineered) |
| Product Manager | JTBD + Feature Matrix + Reviews mining | SWOT | Porter 5F |
| Sales / SDR | Feature Matrix + CPM + Battlecard | SWOT | Porter 5F |
| Analyst / Consultant | CPM + JTBD + Multi-framework overlay | All | None — usa tutti se cliente paga deep |

## Anti-pattern

> "The standard approach — a spreadsheet with feature checkboxes, a few pricing screenshots, and a SWOT template — produces an output that looks like research but rarely generates insights you can act on." — [Olushad Global Solutions](https://www.olushad.com/insights/saas-competitor-analysis-framework)

**Non fare**:
- Solo Feature Matrix (no customer outcome)
- Solo SWOT (no quantitative)
- Solo Porter 5F (no actionable)
- Tutti i framework su tutti i competitor (signal/noise pessimo) → seleziona 2-3 max per ruolo
